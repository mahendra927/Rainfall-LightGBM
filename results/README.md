# Results

All files in this folder are generated by the scripts and correspond to the manuscript as follows.

| Path | Content | Manuscript |
|---|---|---|
| `diagnostics/data_audit.json` | dataset audit and checksum | Dataset section |
| `diagnostics/split_summary.json` | subset sizes and date ranges | Table 2 |
| `chronological/metrics.csv` | all validation and test metrics, A1-A8 | Table 4 |
| `stratified/metrics_by_seed.csv` | 40 runs (8 scenarios × 5 seeds) | Table 5 |
| `predictions/chronological_A*.csv.gz` | test predictions: Location, Date, Rainfall, y_true, prob_yes, y_pred | basis of Tables 8, 9 |
| `predictions/stratified_A*_seed*.csv.gz` | test predictions per seed | basis of Wilcoxon tests |
| `tables/table4_chronological_test.csv` | | Table 4 |
| `tables/table5_stratified_summary.csv` | | Table 5 |
| `tables/table6_isolation_forest.csv`, `table6b_...` | Isolation Forest removal by class | Table 6 |
| `tables/table7_sensitivity.csv`, `sensitivity/` | validation-only sensitivity analysis | Table 7 |
| `tables/table8_block_bootstrap.csv`, `bootstrap/` | paired weekly block bootstrap | Table 8 |
| `wilcoxon/wilcoxon_holm.csv` | exploratory Wilcoxon + Holm | Statistical reliability |
| `tables/table9_false_negatives_by_intensity.csv` | false negatives by rainfall intensity | Table 9 |
| `tables/recall_by_location.csv` | rainfall recall per station | Error analysis |

`Rainfall` appears in the prediction files only for the post-hoc error analysis; it is never a model input.
