# Notebooks

Place the original Google Colab notebook used to produce the manuscript results here
(for example `experiment_original_colab.ipynb`), **with its cell outputs preserved**.

Before committing:

1. Remove Google Drive mounts, personal paths, and any credentials.
2. Keep the printed metrics in the outputs; they document what was actually run.
3. If the notebook and the scripts in `scripts/` differ in any implementation detail,
   describe the difference in this file. The numbers reported in the manuscript must
   correspond to the code that produced them.
